# Security policy

This repository accepts only synthetic `*.invalid` envelope/header addresses, bounded message bodies, recipient states, SMTP
fixtures, and failure receipts. Do not report or attach real credentials, addresses, contact lists, content, attachments, domains,
DNS records, DKIM keys, provider tokens, bounces, complaints, tracking data, production topology, storage paths, or internal mail
metadata.

For a suspected repository vulnerability, open a GitHub security advisory when a public remote exists. Public issues are suitable
only for non-sensitive correctness bugs. This laboratory is not a deployed MTA, mailbox, marketing platform, identity system, or
deliverability service.
